# Symphonic

Työpöytäsoitin Navidrome-palvelimelle. Yksinkertainen, nopea ja viimeistelty
vaihtoehto olemassa oleville Subsonic-asiakkaille.

## Ominaisuudet (tällä hetkellä)

- Yhdistäminen Navidrome-palvelimeen (Subsonic API)
- Albumit, artistit, kappaleet -selaus
- Streaming suoraan palvelimelta
- Soittojono (Play Next / Add to Queue)
- Albumien ja artistien tietosivut
- Artistibiot Last.fm:stä
- Synkronoidut lyriikat LRCLIB:stä
- Tykkäykset, soittolistat
- Kappaleiden tykkäys suoraan albumin kappalelistasta.
- Windowsin tehtäväpalkin esikatselun edellinen-, toista/tauko- ja seuraava-painikkeet.
- Toiston lyhyt äänenvoimakkuuden häivytys tauolle ja takaisin.
- Scrobblaus Navidromelle
- Albumikuvien paikallinen välimuisti vähentää toistuvia latauksia.
- Viimeksi kuunnellut kappaleet ja kuuntelukohdan palautus.
- Kirjaston latauksen edistymisnäyttö ja uudelleenyritys yhteysvirheissä.
- Viimeksi käytetty päänäkymä palautetaan sovelluksen käynnistyessä.
- Valittavat käyttöliittymän väriteemat.
- Windowsissa palvelimen salasana suojataan Windows DPAPI:lla; vanhat asetukset muunnetaan automaattisesti.
- Käyttöliittymä on saatavilla englanniksi, suomeksi ja venäjäksi.

## Teknologia

- Python 3.13
- PySide6 (Qt 6)
- Subsonic API
- LRCLIB, Last.fm
